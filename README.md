EarthArmor Packaging - Front-end Prototype

Overview:
This project is a front-end prototype for a B2B hub that connects food companies, retailers, and manufacturers with suppliers of sustainable packaging solutions. It uses plain HTML, CSS (Bootstrap), and vanilla JavaScript.

Files:
- index.html: Main landing page and UI (suppliers, calculator, resources).
- styles.css: Optional additional styling (most styles are inline in index.html for now).
- app.js: Interactive JS (filtering, calculator, report download, badge generator).
- suppliers.json: Sample supplier data used for the directory.

How to run:
Open `index.html` in a browser (double-click or serve via a static file server).
